# Prism

Prism is a customizable macOS browser built around speed, focus, and personal control.

It combines a clean browsing experience with flexible tabs, polished visual customization, productivity tools, sidebar workflows, home widgets, site controls, and audio features designed to make the browser feel personal instead of generic.

## Highlights

- Smooth tab management with groups, pinned tabs, vertical layouts, and keyboard shortcuts
- Customizable toolbar, bottom bar, sidebar, and home screen
- Built-in home dashboard with widgets, quick links, notes, bookmarks, and productivity tools
- Site controls for privacy, appearance, permissions, and browsing behavior
- Optional ad, tracker, cookie, and website protection controls
- Audio tools including media controls and equalizer features
- Profile-based customization, so each profile can have its own layout and style
- Polished macOS-first interface with glass-style UI, wallpapers, and responsive controls

## Distribution

Prism is distributed as a macOS app download.

The public download contains only the built application package. Source code, internal project files, signing files, and development assets are not included.

## Privacy

Prism is designed to keep user control at the center. Features that need permissions, such as audio-related tools or website access, are shown clearly inside the app before use.

## Status

Prism is currently in active development. Some experimental features may change as the browser improves.
